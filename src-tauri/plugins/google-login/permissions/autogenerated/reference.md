## Default Permission

Permite abrir o login com Google nativo do Android.

#### This default permission set includes the following:

- `allow-entrar`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`google-login:allow-entrar`

</td>
<td>

Enables the entrar command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`google-login:deny-entrar`

</td>
<td>

Denies the entrar command without any pre-configured scope.

</td>
</tr>
</table>
